# Paper Directory

The paper source is intentionally not part of the bootstrap archival release.

The TeX source will be committed after the Zenodo concept DOI is available and the repository
owner has approved the manuscript for public release. The paper should cite:

- the stable Zenodo concept DOI;
- the exact GitHub release tag;
- the exact Git commit SHA.

Do not embed a version-specific Zenodo DOI in the paper. That avoids a release/DOI recursion:
Zenodo can mint a version DOI for the release after the tag is archived, and that DOI can be
recorded in release notes or a later metadata-only update.

Generated auxiliary TeX files must not be committed. The final PDF may be committed only if the
repository owner explicitly requests it.
